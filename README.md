# YoChat

YoChat هو تطبيق دردشة عالمي يستخدم Firebase لتخزين الرسائل والمستخدمين، مع دعم تسجيل الدخول باستخدام حسابات Google. يوفر التطبيق واجهة مستخدم بسيطة وسهلة الاستخدام، بالإضافة إلى دعم الرسائل النصية الفورية.

## المميزات

- تسجيل الدخول باستخدام حساب Google
- دعم الرسائل النصية الفورية
- عرض قائمة المستخدمين
- إرسال واستقبال الرسائل بشكل فوري
- واجهة مستخدم نظيفة وسهلة الاستخدام

## الأدوات والتقنيات المستخدمة

- **HTML5** - لإنشاء الهيكل الأساسي للصفحات
- **CSS3** - لتنسيق وتصميم واجهة المستخدم
- **JavaScript** - لإضافة التفاعلية ومنطق التطبيق
- **Firebase** - لتخزين الرسائل والمستخدمين، ودعم المصادقة عبر Google
- **Firestore** - لتخزين واسترجاع الرسائل
- **Google Firebase Authentication** - لإجراء المصادقة باستخدام حساب Google

## كيفية الإعداد والتشغيل

### المتطلبات المبدئية

1. تأكد من أنك قد قمت بتثبيت **Node.js** على جهازك. يمكنك تنزيله من [هنا](https://nodejs.org/).
2. تأكد من أنك قد قمت بإنشاء مشروع في **Firebase**. إذا لم تكن قد قمت بذلك، يمكنك اتباع [هذه التعليمات](https://firebase.google.com/docs/web/setup) لإنشاء مشروع Firebase.
